# Penn State Behrend Media & Communication — Independent Concept Site

**Files:** `index.html`, `assets/banner-hero-photo.webp`, `assets/banner-studio.webp`, `assets/banner-hero.webp`.

This is a **standalone, single-page website**. It does not depend on, embed, or link to the author's teaching portfolio or personal website. Nothing has been published online yet.

## See it

Open `index.html` to preview it. For a public link separate from your current GitHub Pages site, create a **new repository** (for example, `behrend-media-communication`) and place the full contents of this folder at the repository root. In GitHub: Settings → Pages → Deploy from a branch → main → /(root). The URL will be `https://YOUR_USERNAME.github.io/behrend-media-communication/` (assuming this repo name), independent of your personal website repo. A separate domain can be used later if institutional approval and domain control allow.

Consult the program chair, school communications, and PSU brand guidance before publishing it as a college-related site. The footer preserves a clear concept-site notice.
